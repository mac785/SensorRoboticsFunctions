# SensorRoboticsFunctions
Group of functions and 1 program for THA1 of Algorithms for Sensor-Based Robotics

Description:
Functions titled "x2y_my.m" are the functions to convert between one representation to another.
For example, "quat2rotm_my.m" converts from a quaternion to rotation matrix. These are for PA questions 1 and 2.

"screw_motion_program.m" is for PA question 3. It will prompt the user if the test case should be run (y/n) and will run for the test case. Otherwise, it will ask for custom values.
